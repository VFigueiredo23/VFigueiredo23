## 🗺️ Arquitetura em 20 segundos
- **Back-end**: Django + DRF, JWT (ou Token) quando necessário, serializers bem definidos e versionamento de rotas.  
- **Front Mobile**: React Native (Expo), consumo de APIs com `fetch`/`axios`, `expo-router` para navegação, listas performáticas.  
- **Dados**: SQLite no dev, PostgreSQL no prod.  
- **DevX**: logs claros, `.env` bem organizado e deploy simples (sem sofrimento).
